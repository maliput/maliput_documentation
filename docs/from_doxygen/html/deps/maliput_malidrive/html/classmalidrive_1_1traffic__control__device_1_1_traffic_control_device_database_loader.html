TrafficControlDeviceDatabaseLoader Class Reference

Detailed Description

Loads traffic control device definitions from a YAML database file or content and provides a lookup interface for querying definitions by TrafficControlDeviceFingerprint.

The loader is backed by the TrafficControlDeviceParser. When a database is provided at construction time the file is parsed immediately; subsequent Lookup calls perform a linear scan with specificity ranking.

If no database is provided (std::nullopt) the loader starts empty and all Lookup calls will return std::nullopt.
