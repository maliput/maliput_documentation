RoadObjectBookBuilder Class Reference

Detailed Description

Builds a maliput::api::objects::RoadObjectBook populated with maliput::api::objects::RoadObject instances derived from the XODR <object> elements across all roads.

Follows the functor pattern: construct with the required inputs and call operator()() to produce the book.
