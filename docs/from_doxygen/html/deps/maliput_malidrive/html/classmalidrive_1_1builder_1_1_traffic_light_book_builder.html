TrafficLightBookBuilder Class Reference

Detailed Description

Builds a maliput::api::rules::TrafficLightBook.

An initial maliput::api::rules::TrafficLightBook is constructed from the file specified in traffic_light_book_path. When traffic_signal_db_path is set, the book is also populated by iterating all XODR signals in road_geometry and constructing one maliput::api::rules::TrafficLight per signal that has a matching entry in the YAML database. Otherwise, the existing file-based traffic_light_book_path is used (or an empty book when neither parameter is set).
