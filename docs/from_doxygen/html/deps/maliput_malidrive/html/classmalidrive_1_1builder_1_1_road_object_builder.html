RoadObjectBuilder Class Reference

Detailed Description

Builds a single maliput::api::objects::RoadObject from either an XODR xodr::object::Object or an XODR xodr::signal::Signal.

The builder follows the functor pattern: construct it with all required inputs and an explicit source selector, then call operator()() to produce the result.
