TrafficSignalBooksBuilder Class Reference

Detailed Description

Builds a maliput::api::rules::TrafficLightBook and a maliput::api::rules::TrafficSignBook in a single pass over the XODR signals and the traffic signal YAML database.

Compared to the alternative design (separate TrafficLightBookBuilder / TrafficSignBookBuilder), this builder:

  • Parses the YAML database exactly once.
  • Routes each XODR signal to the right book using the sign_type field of the matching traffic_control_device::TrafficControlDeviceDefinition:
    • "traffic_light" → maliput::api::rules::TrafficLight added to the TrafficLightBook.
    • any other value → maliput::api::rules::TrafficSign added to the TrafficSignBook.
  • Fetches cross-road signal references for all matched signals (both traffic lights and traffic signs may be referenced across roads).
