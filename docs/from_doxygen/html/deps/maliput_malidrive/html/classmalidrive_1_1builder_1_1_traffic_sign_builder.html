TrafficSignBuilder Class Reference

Detailed Description

Builds a single maliput::api::rules::TrafficSign from a XODR xodr::signal::Signal and its matching definition in the traffic signal YAML database.

The builder follows the functor pattern: construct it with all required inputs and call operator()() to produce the result.

When no matching traffic_control_device::TrafficControlDeviceDefinition is found in the loader for the given signal's type/subtype/country/country_revision fingerprint, or the device_type is not traffic_control_device::TrafficControlDeviceType::kTrafficSign, the builder returns nullptr.
