RoadMarkingBuilder Class Reference

Detailed Description

Builds a single maliput::api::objects::RoadMarking from either an XODR xodr::object::Object or an XODR xodr::signal::Signal together with its matching definition in the traffic control device YAML database.

The builder follows the functor pattern: construct it with all required inputs and call operator()() to produce the result.

The source type must be selected explicitly at construction time, and only the matching source payload is accepted.

When no matching traffic_control_device::TrafficControlDeviceDefinition is found in the loader for the selected source fingerprint, or the device_type is not traffic_control_device::TrafficControlDeviceType::kRoadMarking, the builder returns nullptr.
