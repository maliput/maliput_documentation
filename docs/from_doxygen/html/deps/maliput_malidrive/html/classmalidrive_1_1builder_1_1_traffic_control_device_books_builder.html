TrafficControlDeviceBooksBuilder Class Reference

Detailed Description

Builds all four traffic control device books in a single pass over the XODR signals and objects, using a shared traffic control device YAML database.

This unified builder ensures the database is loaded exactly once and each XODR element is routed to the appropriate book based on its device_type:

  • XODR signals:
    • "TrafficLight" → TrafficLightBook
    • "TrafficSign" → TrafficSignBook
    • Other/no match → skipped
  • XODR objects:
    • "RoadMarking" → RoadMarkingBook
    • "RoadObject" → RoadObjectBook
    • No match → skipped
