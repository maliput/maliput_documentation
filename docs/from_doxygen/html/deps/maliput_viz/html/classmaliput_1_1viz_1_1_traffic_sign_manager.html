TrafficSignManager Class Referencefinal

Detailed Description

Class that creates and owns rendering visuals for traffic signs.

Each sign is represented as a single colored box matching the sign's bounding box. The manager also supports proximity-based hit testing so that a scene click can be resolved to the nearest traffic sign.
