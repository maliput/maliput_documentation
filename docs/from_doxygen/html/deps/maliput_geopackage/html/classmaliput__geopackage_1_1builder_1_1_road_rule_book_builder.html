RoadRuleBookBuilder Class Reference

Detailed Description

Functor to build a maliput::api::rules::RoadRulebook.

The building procedure is:

  1. If a YAML file path is provided, loads rules from the file.
  2. Adds GeoPackage-sourced speed limit rules on top (both new maliput::api::rules::RangeValueRule entries and deprecated maliput::api::rules::SpeedLimitRule entries for backward compatibility).
