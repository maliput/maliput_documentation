RuleRegistryBuilder Class Reference

Detailed Description

Functor to build a maliput::api::rules::RuleRegistry.

The building procedure is:

  1. If a YAML file path is provided, loads rule types from the file.
  2. If GeoPackage speed limits are provided and the Speed-Limit Rule Type is not yet registered, registers it with the speed limit ranges extracted from the GeoPackage data.
