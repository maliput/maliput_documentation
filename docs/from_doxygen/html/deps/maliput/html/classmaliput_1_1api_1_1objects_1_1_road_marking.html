RoadMarking Class Referencefinal

Detailed Description

Models a physical road marking — a painted or applied marking on the road surface that conveys regulatory, warning, or guidance information to road users.

Examples include stop markings, crosswalks, directional arrows, speed limit markings, parking space delineations, and railroad crossings.

Note
RoadMarking intentionally does not hold a reference to any Rule. The linkage between a marking and its corresponding rule is established in the opposite direction: a Rule's RelatedUniqueIds can reference a RoadMarking's ID. This mirrors the existing TrafficLight <-> Rule and TrafficSign <-> Rule coupling patterns.

Parameters
idThe marking's unique identifier. It must be unique within the RoadMarkingBook that contains this marking.
typeThe type of marking (e.g., RoadMarkingType::kStop, RoadMarkingType::kCrosswalk, RoadMarkingType::kSpeedLimit).
positionThe position of the marking relative to the road network.
orientationThe rotational offset of the marking's frame relative to the road network's Inertial frame.
bounding_boxThe bounding box of the marking.
related_lanesThe lanes that this marking is physically relevant to. For example, a crosswalk marking is relevant to the lanes it spans.
nameAn optional human-readable name for the marking.
outlinesOptional detailed shape outlines. When defined, they supersede the bounding box for precise geometry.
valueAn optional numeric value associated with the marking (e.g., 60 km/h for a speed limit marking).
