Outline Class Reference

Detailed Description

Represents the outline of a road object.

An outline is a sequence of corner points that define the 2D or 3D shape of an object. Outlines can be closed (forming a polygon) or open (forming a polyline). When outlines are defined on a RoadObject, they supersede the bounding box for precise geometry representation.
